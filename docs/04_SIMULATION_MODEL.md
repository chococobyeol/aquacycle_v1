## 1. 표기와 출처 사용 원칙

각 규칙은 다음 네 종류 중 하나로 표시한다.

- **관찰 근거**: 논문·공공기관·공식 모델 문서에서 확인되는 관계
- **현재 구현**: 2026-07-26 현재 플레이어블 코드에 존재하는 동작
- **후속 설계**: 현재 범위 다음에 검토하거나 보정할 동작
- **게임 보정**: 실제 단위나 시간을 그대로 재현하지 않고 플레이 가능한 속도와 범위로 조정한 값

출처는 모델의 **관계와 상대적 경향**을 뒷받침한다. 논문에 등장하는 종·계통·사육 조건이 게임 수조와 다르면 해당 논문의 수치를 그대로 복사하지 않는다. 게임 상수는 자동 시뮬레이션과 플레이 테스트로 보정하며, 실측 단위를 표방하지 않는 값에는 실제 단위를 붙이지 않는다.

예를 들어 체리새우의 야외 수명이 약 10~20개월 범위로 달라질 수 있다는 연구 관계는 자연사와 세대교체를 구현할 근거다. 현재 게임 수명 `1,800~3,000` 시뮬레이션초는 그 기간을 그대로 환산한 값이 아니라 한 번의 실험에서 여러 세대를 볼 수 있게 한 시간 압축이다.

`부착 분해균막`은 표면 유기물을 처리하고, 그 일부가 탈락하면 물기둥의
`부유 분해균` 농도장으로 이동한다. 부유 분해균은 공통 물 흐름으로 수송되고
용존·미세 입자 유기물을 분해하며, 물벼룩과 같은 물 셀에 있을 때 낮은
효율의 보조 먹이로 여과될 수 있다. 질산화균은 현재처럼 표면 필름을
중심으로 유지하고 탈락한 양은 정착 전파용 부유 접종체로만 압축한다.

| 대상 | 현재 계산 단위 | 비고 |
|---|---|---|
| 구조물·바닥 생산자 | 표면 셀별 두 조류와 나사말 생체량 | 각 종 `0~1`, 같은 표면 공간 공유. 나사말은 바닥에만 정착 |
| 체리새우 | 암수·나이·에너지·몸 질량을 가진 개별 개체 | 이동은 연속 2D 좌표 |
| 송사리 | 알·치어·어린 개체·성체의 개별 개체 | 국소 유영·포식·구애·산란·부화 |
| 분해균·질산화군집 | 표면 셀별 기능군 필름 생체량 | 개별 세균이나 종 조성은 계산하지 않음 |
| 부유 분해균·식물플랑크톤 | `36×20` 위치별 생체량 | 공통 물 흐름·국소 확산·생태 반응 |
| 큰물벼룩 | 나이·세대·몸 질량·저장량을 가진 개별 개체 | 연속 2D 좌표로 움직이며 화면의 한 마리와 계산 개체가 1:1 대응 |
| 고형 찌꺼기 | `36×20` 위치별 질량 | 용출 전에는 물과 같은 속도로 이동하지 않음 |
| 유기물·독성 노폐물·영양염·용존산소 | 각각 `36×20` 농도장 | 개별 국소 확산 + 공통 물 흐름 |
| 물속 무기탄소 | `36×20` 농도장 | 다른 용존 성분과 같은 물 흐름 사용 |
| 공기층 CO₂·O₂ | 기체별 저장고 값 하나 | 수면을 통해 물과 교환 |
| 수온·물 흐름 | `36×20` 열에너지장과 2D 속도장 | 광원·경계 열교환·구조물·부력 반영 |

### 2.2 현재 계산 순서

기본 생태 스텝은 `0.25` 시뮬레이션초이며, 32배속 이상에서는 `1`초로 묶는다.

```text
공간 열전도·경계 열교환·부력 유동
→ 낮·밤 광량장 갱신 → 생산자 총광합성·호흡·스트레스·경쟁·표면 전파
→ 새우 섭식·에너지·성장·번식·사망
→ 송사리 유영·국소 포식·에너지·구애·산란·부화·사망
→ 균 필름의 먹이·산소 반응
→ 부유 분해균·식물플랑크톤·물벼룩 반응
→ 다섯 용존 성분의 국소 확산과 공통 유량 수송
→ 닫힌 공기층과 기체 교환
→ 미션 판정과 관찰 스냅샷
```

기존 `bulkMixing`은 제거했다. 온도 차이에서 계산한 하나의 속도·경계 유량을 유기물·암모니아성 노폐물·영양염·용존산소·무기탄소가 함께 사용한다. 따라서 먼 두 위치가 평균 혼합 항으로 직접 가까워지지 않고 실제 격자 경계를 거쳐 이동한다.

### 2.3 현재 공간 수송 보정값

아래 값은 실제 확산계수가 아니라 `초⁻¹` 단위의 게임 보정률이다. 공통 방향성 유동이 해상하지 못하는 분자·소규모 혼합만 나타낸다.

| 장 | 국소 이웃 확산 |
|---|---:|
| 용존 유기물 | 0.045 |
| 암모니아성 독성 노폐물 | 0.09 |
| 영양염 | 0.07 |
| 용존산소 | 0.12 |
| 물속 무기탄소 | 0.10 |

국소 확산과 공통 경계 유량은 모두 한 셀이 잃은 양을 다른 셀에 그대로 더한다. 양수성과 셀 용량을 지키는 송신·수신 제한자를 사용하며, 수송만으로 총량을 바꾸지 않는다.

## 3. 현재 공통 열·물질 수송 모델

### 3.1 목표

현재 모델은 산업용 CFD의 정확한 난류를 재현하는 것이 아니라, 다음 질문에 공간적으로 납득할 수 있는 답을 제공한다.

- 왜 이 위치의 물이 더 따뜻하거나 차가운가?
- 왜 표면의 산소가 아래쪽으로 전달되었는가?
- 왜 사체 주변의 유기물과 암모니아가 이 방향으로 퍼졌는가?
- 왜 돌 뒤쪽과 흐름이 약한 곳에 물질이 오래 남는가?
- 왜 조명·유리벽·바닥 배치가 수온과 수질의 경로를 함께 바꾸는가?

이를 위해 다섯 용존 성분과 공간 수온을 **같은 물 흐름을 공유하는 보존형 수송 계층**으로 통합했다.

### 3.2 모델 수준

채택한 수준은 `36×20` 저해상도 2D 부력 유동장이다.

```text
각 물 셀
├─ 온도 또는 열에너지
├─ 가로·세로 유속
├─ 물 비율·구조물 점유율·통과 저항
├─ 용존산소
├─ 물속 무기탄소
├─ 용존 유기물
├─ 암모니아성 독성 노폐물
└─ 영양염
```

고형 찌꺼기, 표면 조류와 균 필름은 이 배열에 합치지 않는다. 고형 찌꺼기는 침전·부유 상태에 따라 별도 이동하고, 조류와 균은 구조물 표면에 남으면서 인접한 물 셀과 반응한다.

### 3.3 유지할 물리 관계

온도와 각 용존 성분은 다음의 이류–확산–반응 구조를 따른다.

```text
온도 변화
= 물 흐름이 운반한 열
+ 주변 물질과의 열전도
+ 흡수한 광원 에너지
+ 외부 공기와의 열교환

용존 성분 변화
= 물 흐름이 운반한 질량
+ 성분별 분자·미해상 혼합
+ 생물학적 생성과 소비
```

수학적으로는 다음 관계를 저해상도로 이산화한다.

```text
∂T/∂t + u·∇T = α∇²T + Q/(ρcp)
∂Ci/∂t + ∇·(u Ci) = Di∇²Ci + Ri
```

- `T`: 온도
- `u`: 공통 물의 속도
- `Ci`: 산소·탄소·유기물·노폐물·영양염 각각의 농도
- `α`, `Di`: 열과 성분별 확산 계수
- `Q`: 조명·외부 경계에서 들어오거나 나가는 열
- `Ri`: 광합성·호흡·분해·질산화 같은 반응

### 3.4 자연 대류

물의 온도 차이가 작다는 범위에서는 Boussinesq 근사를 사용한다. 밀도를 모든 계산에서 바꾸지 않고 온도 차이가 만드는 부력에만 반영한다.

```text
세로 부력 = 부력계수 × (현재 온도 - 기준 온도)
```

그 결과 다음 관계가 나온다.

- 아래에서 데워진 물은 상승한다.
- 유리벽이나 수면에서 식은 물은 하강한다.
- 위쪽만 따뜻한 층은 비교적 안정되어 대류가 약해진다.
- 국소 가열과 측면 냉각이 함께 있으면 완만한 순환이 생긴다.

유속이 한 셀에 쌓여 물이 생성·소멸하는 것처럼 보이지 않도록 `0.5` 시뮬레이션초마다 압력 투영을 수행한다. 현재 `36×20` 격자는 Jacobi 반복 `14`회를 사용한다. Jos Stam의 실시간 유체 방법은 작은 격자에서 속도와 압력 투영을 구성하는 구현 참고로 사용하되, 물질 장부에는 질량 손실이 생길 수 있는 단순 반라그랑주 스칼라 이류를 그대로 사용하지 않는다.

### 3.5 보존형 물질 이동

폐쇄 수조에서 수치 오차로 산소·질소·탄소가 사라지지 않도록 셀 중심값을 임의로 보간해 덮어쓰지 않는다. 셀 경계마다 물의 체적 유량을 한 번 계산하고, 같은 유량으로 모든 용존 성분을 옮긴다.

```text
경계 유량 F가 A → B라면

A의 감소량 = F × A의 농도 × dt
B의 증가량 = A의 감소량
```

내부 경계에서는 한쪽이 잃은 양이 다른 쪽에 정확히 더해져야 한다. 광합성·섭식·호흡·분해처럼 형태가 바뀌는 반응도 기존 C:N 장부에서 출발 물질과 도착 물질을 함께 기록한다. 외부와 실제로 교환되는 열과 기체만 별도 경계 장부에 기록한다.

현재 구현은 양수성과 보존이 명확한 1차 상류 유한체적 수송을 사용한다. 수치 확산이 군락·수질 지도를 지나치게 흐리면 이후 제한자 기반 2차 수송을 검토한다. MITgcm과 MOM6의 추적자 수송 문서는 흐름과 일치하는 경계 flux, 단조성 및 물질 보존을 유지하는 참고 기준으로 사용한다.

### 3.6 전도와 복사열

열전도는 물과 물 사이뿐 아니라 물·돌·바닥·유리 사이에서 처리한다.

```text
전도 열량 = 경계 유효 열전도도 × (이웃 온도 - 현재 온도) × dt
```

각 구조물의 보이는 외곽을 셀당 `3×3` 표본으로 `36×20` 격자에 부분 점유율로 투영하고, 재질별 열용량과 열전도도를 부여한다. 돌 전체를 온도 하나로 즉시 균일화하지 않고 여러 격자 구간이 천천히 열을 전달하게 한다.

복사열은 모든 셀 사이의 복사 교환을 풀지 않는다. 현재 광량장이 계산한 직접광·가림·산란·반사광을 에너지 입력으로 재사용한다.

```text
흡수열 = 광량 × 물질별 흡수율 × dt
```

물, 돌, 바닥은 서로 다른 비율로 빛을 흡수한다. 빛을 받은 구조물이 먼저 데워지고 인접한 물로 전도할 수 있어야 한다. 수면과 유리벽은 실내 온도와 Newton형 경계 열교환을 하며, 내부 전도와 대류는 열을 재배치할 뿐 새 열을 만들지 않는다.

### 3.7 2D 구조물의 보정

화면의 돌을 완전 불투과 벽으로 바꾸면 현실에서는 앞뒤로 지나갈 물까지 막히는 문제가 생긴다. 구조물은 다음 두 값을 구분한다.

- `solidFraction`: 열용량과 열전도에 사용되는 실제 고체 점유율
- `permeability` 또는 `drag`: 3차원 앞뒤 우회를 압축한 물 통과 저항

돌 중심은 흐름이 매우 약하고 가장자리는 일부가 통과하도록 한다. 이 방식은 구조물 뒤의 느린 영역은 만들되, 2D 화면에서 밀폐되지 않은 틈이 영구적인 무산소 포켓으로 오판되는 것을 줄인다.

### 3.8 계산 순서

```text
1. 조명·실내 공기·생물 반응에서 열과 물질 source/sink 기록
2. 열전도와 성분별 국소 확산
3. 온도 차이에서 부력 추가
4. 유속 이류·저항·점성 적용
5. 압력 투영으로 발산 억제
6. 셀 경계 물 유량 계산
7. 같은 경계 유량으로 열과 모든 용존 성분 보존형 이동
8. 수면 기체 교환과 경계 열교환
9. 음수·비유한값·장부 오차 검증
```

반응과 수송의 순서가 결과를 크게 바꾸지 않도록 필요하면 반응을 반 스텝씩 나누는 연산자 분할을 사용한다. 32·64배속의 `1초` 생태 스텝에서 경계 유량이 한 셀 전체를 초과하면 1~4회의 수송 하위 스텝을 사용한다.

### 3.9 예상 성능

격자는 720셀이다. 속도 2개, 압력·발산 임시 배열, 온도와 다섯 용존 성분을 추가해도 메모리는 매우 작다. 비용은 현재 네 필드의 확산보다 증가하지만, 모든 성분이 같은 경계 유량과 장애물 정보를 재사용하므로 변수 하나를 추가할 때마다 유체 전체를 다시 풀지는 않는다.

현재 구현 기준은 다음과 같다.

- Web Worker의 생태 스텝에서만 계산하고 렌더 프레임마다 풀지 않는다.
- `Float32Array`와 재사용 scratch 배열을 사용한다.
- 구조물이 움직이거나 바뀔 때만 고체 점유·저항 지도를 다시 만든다.
- 고배속에서도 압력 반복 `14`회, 열 하위 스텝 최대 `4`회라는 명시적 상한을 둔다.
- 64배속 30분 회귀는 개발 환경에서 약 `6.2`초, 2시간 폐쇄 생태계 회귀는 약 `35.4`초에 완료됐다.

## 4. 조류 모델과 근거

### 4.1 유지하는 현실 관계

**관찰 근거**는 다음과 같다.

- 광합성 생물의 빛 반응은 일반적으로 저광량 제한, 포화, 경우에 따라 강광 저해를 가진다.
- 같은 속의 조류도 계통과 순응 조건에 따라 최적 광량과 수온이 다를 수 있다.
- 붓뚜껑말속은 사상형 녹조류로, 수조 화면에서는 개별 세포보다 표면 군락의 질감으로 보는 편이 맞다.
- `Nitzschia palea`는 저광·고광 조건에 광순응할 수 있으며, 종 전체를 “밝으면 즉사하는 규조류”로 정의할 근거는 없다.
- 부착 규조류와 다른 미생물은 표면 생물막을 이루며 빛·영양염·섭식의 영향을 함께 받는다.

### 4.2 현재 구현

두 부착 조류와 나사말은 각 표면 셀의 `0~1` 생체량으로 계산한다. 나사말은 바닥 셀을 뿌리점으로 사용하는 개별 포기(ramet)로 추가 추적한다. 포기는 나이·개체별 수명·느리게 변하는 잎 구조 크기·건강·러너 준비도·부모 포기를 가진다. 밤의 호흡으로 저장 생체량이 조금 줄더라도 잎 길이가 매일 수축하지 않지만, 장기 자원 부족과 노쇠에는 잎이 실제로 줄고 변색된다.

지급 포기는 이미 뿌리내린 어린 포기로 시작해 `360`초에 성체가 된다. 개체별 압축 수명은 결정적 난수로 `2,400~3,300`초이며 수명의 `82%`부터 노쇠 단계에 들어간다. 건강한 성체는 약 `600`초의 환경 적합 누적마다 가까운 빈 바닥 셀을 찾아 러너 자손을 만든다. 이때 부모의 실제 생체량 `0.16`을 딸 포기로 옮기므로 번식 자체가 물질을 복제하지 않는다. 적합한 빈 바닥이 없으면 준비도만 유지하고 강제로 번식하지 않는다. 숨은 최대 포기 수는 두지 않으며 바닥 공간·광량·수온·무기질소·무기탄소와 부모 저장량이 확장을 제한한다.

생체량 `0.055` 미만 상태가 `150`초 지속되거나 개체별 수명에 도달하면 포기는 죽는다. 남은 생체량 전부를 기존 조류 자연 소실과 같은 찌꺼기 경로로 보내 분해균·질산화균·영양염·무기탄소 순환에 연결한다. 사용자가 심은 포기와 러너 자손은 저장 파일에 나이·수명·잎 구조·러너 진행도를 함께 기록한다. 관찰창에서는 어린 포기/성체/노쇠 수, 선택 포기의 나이·건강·러너 준비도와 자손 수를 표시한다.

```text
기준 순성장률 = 종별 구간 선형 광량 곡선
수온 적합도 = 종별 구간 선형 수온 곡선

기준 총광합성 = max(0, 기준 순성장률 + 24°C 기준 호흡률)
총광합성 = 기준 총광합성 × 수온 적합도
호흡 = 24°C 기준 호흡률 × theta^(수온-24)
광·수온 스트레스 = 기준 비호흡 손실 + 부적합 수온 손실
실제 새 생체량 = 기존량 × 총광합성 × 빈 표면 × 영양·탄소 제한 × dt
순변화 = 실제 새 생체량 - 호흡 - 광·수온 스트레스 - 자연 소실
```

기존 순성장 곡선은 24°C에서 같은 결과를 내도록 총광합성·호흡·비호흡 손실로 분해했다. 따라서 낮에는 총광합성이 무기질소와 무기탄소를 실제로 고정하고 산소를 만들며, 어두울 때는 총광합성이 0이 되어도 호흡이 계속되어 산소를 소비하고 무기탄소·암모니아성 질소를 돌려놓는다. 산소가 바닥나 요청된 호흡을 모두 수행하지 못한 생체량과 광·수온 스트레스 손실은 고형 찌꺼기로 돌아간다. 생리 함수는 어둠의 원인을 받지 않는다. 같은 국소 광량·수온·자원이라면 밤, 구조물 그림자, 꺼진 전등에서 모두 같은 반응을 반환한다. 광순응을 이후 도입한다면 시나리오 구분이 아니라 각 군락이 실제로 겪은 누적 광량 이력으로 계산한다.

미션 6의 주기는 `새벽 30초 → 낮 240초 → 해질녘 30초 → 밤 60초`이며 **수면 전체에 들어오는 자연광**이 낮의 `100%`에서 밤의 `4.5%`까지 완만하게 변한다. 숨은 천장 전등은 사용하지 않는다. 자연광과 전등은 별도 성장 규칙이 아니라 위치·폭·방향·시간 배율이 다른 공통 광원 자료로 만들고, 동일한 구조물 차폐·수심 감쇠·산란·1차 반사 계산에 넣은 뒤 한 지점에서 합산한다. 생산자는 광원의 종류가 아닌 이 합산 광량에만 반응한다. 광량 오버레이·표면 광량·수온 입력도 같은 광량장을 사용한다. 고배속에서 매 생태 틱마다 레이캐스팅하지 않도록 새벽·해질녘은 자연광 배율이 4% 이상 달라질 때 광량장을 다시 계산하되 위상 경계는 정확히 갱신한다.

세 생산자는 같은 표면 수용력을 공유하고, 현재 환경에서 상대 순성장률이 높은 종이 서서히 자리를 대체한다. 발달한 붓뚜껑말 군락은 낮은 규조류 막을 추가로 가리는 경쟁 보정을 가진다.

표면 전파는 새 생체량 생성이 아니다. 출발 셀에서 실제 생체량을 차감해 인접·접촉 표면으로 옮기며, 도착지의 빛·수온과 빈 공간이 정착량을 제한한다.

현재 반응곡선의 꼭짓점은 다음과 같다. 두 꼭짓점 사이의 값은 선형 보간한다.

| 종 | 상대 광량 `0~100`에 따른 순성장률 `/초` |
|---|---|
| 붓뚜껑말속 | `0:-0.004, 15:-0.002, 28:0, 45:0.042, 68:0.068, 82:0.046, 94:0.006, 100:-0.024` |
| `Nitzschia palea` | `0:-0.0035, 6:-0.001, 12:0.006, 25:0.055, 38:0.062, 55:0.034, 72:0.01, 86:-0.009, 100:-0.028` |
| 나사말 | `0:-0.002, 10:-0.001, 18:0, 35:0.018, 58:0.032, 78:0.036, 100:0.031` |

| 종 | 수온 °C에 따른 성장 적합도 `0~1` |
|---|---|
| 붓뚜껑말속 | `8:0.12, 14:0.58, 20:0.92, 24:1, 30:0.72, 36:0.08` |
| `Nitzschia palea` | `8:0.18, 15:0.65, 22:0.92, 28:1, 34:0.58, 40:0.06` |
| 나사말 | `8:0.18, 15:0.62, 21:0.95, 25:1, 30:0.72, 36:0.08` |

이 표는 종의 보편적 실측곡선이 아니라 아래 연구에서 확인한 정성적 관계를 미션 시간에 맞게 압축한 **현재 게임 곡선**이다. 빛·수온과 별도로 총 생체량 생산에는 `N/(0.5+N)`과 `C/(8+C)`의 무기질소·무기탄소 제한을 적용한다. 제한된 생산이 호흡·환경 소실을 보충하지 못하면 양의 성장만 느려지는 것이 아니라 실제 생체량이 감소한다. 질소 반포화값 `0.5`는 닫힌 수조에서 재무기화되어 돌아오는 `0.2~3` 농도대에 부착조류가 계속 반응하도록 맞춘 압축 농도 상수이며, 질소나 생체량을 추가하지 않는다.

### 4.3 게임 보정과 한계

- 광량 `0~100`은 lux가 아니라 조류 성장에 사용되는 상대적 광합성 유효광량이다.
- 광량·수온 곡선의 정확한 꼭짓점은 미션의 공간 퍼즐과 관찰 가능 시간을 위한 보정값이다.
- 분해되지 않은 유기물이 물을 가득 채워도 광학적으로 아무 영향이 없던 문제를 막기 위해 생리 곡선에 넣는 실제 유효광량을 `Ieff = I × exp(-0.025 × 유기물)`로 계산한다. 이는 유색 용존 유기물과 부유 유기물이 빛을 흡수·산란한다는 관계를 Beer–Lambert형으로 압축한 게임식이며, `0.025`는 실제 농도 단위의 흡광계수가 아니다. 유기물 `0/5/100`에서 투과율은 각각 약 `1.00/0.88/0.08`이고, 탁도가 심하면 보상광점 아래로 내려가 생체량도 감소할 수 있다.
- 용존산소가 실제 호흡량을 충당하지 못하면 미지급 유지대사를 면제하지 않는다. 호흡한 몫은 무기탄소·암모니아로 돌아가고, 충당하지 못한 몫은 살아 있는 조류 생체량에서 빠져 detritus로 이동한다.
- `Nitzschia palea`는 실제 모든 계통의 대표가 아니라 **저광량에 순응한 게임 내 수조 계통**으로 명시한다.
- 규조류가 필요로 하는 규산염을 현재 `nutrients`와 별도로 계산하지 않는다. 규조류 장기 제한을 더 깊게 다룰 때 독립 규산염 변수를 검토한다.
- 실제 부착 생물막은 조류·세균·균류·원생생물·고형물이 섞인 복합체지만, 현재 화면과 먹이 계산은 두 조류와 두 균 기능군으로 나눈다.

## 5. 체리새우 모델과 근거

### 5.1 유지하는 현실 관계

**관찰 근거**는 다음과 같다.

- 체리새우 `Neocaridina davidi`는 표면의 조류·생물막·유기 찌꺼기를 이용할 수 있다.
- 바이오필름 기반 사육계에서 번식부터 어린 개체 성장까지 생활사를 완성할 수 있다.
- 먹이와 몸의 자원은 성장·유지·번식 사이에 배분되며, 번식에는 비용이 따른다.
- 자연 개체군에는 계절적 가입과 크기·성별·수명에 따른 세대교체가 있다.
- 밀도, 수온, 먹이와 수질은 성장·번식·생존에 영향을 줄 수 있다.

### 5.2 현재 구현

체리새우는 개별 개체로 다음 상태를 가진다.

```text
위치·속도·방향
생활 단계·성별·나이·개체 수명
몸·저장 질량에서 계산한 영양 상태·건강
몸 생체량·저장 생체량·번식 저장 생체량
최근 섭식·누적 섭식
개체별 성숙 목표·난소 성숙도·번식 주기 번호
보존된 난소 물질·교미 진행·개체별 포란 진행
행동 상태와 먹이 목표
```

새우가 직접 식별하는 먹이 셀은 영양 상태와 관계없이 현재 위치 반경
`64` 안으로 제한한다. 이전의 굶주림 반경 `240` 확장 검색은 없앴다.
그 대신 실제 조류와 먹을 수 있는 균 필름이 비물질성 용존 먹이 단서의
소스가 된다. 소스 반응은 표면 먹이 생체량에 대한 연속 Hill 2차
포화식으로 미량 배경 신호를 억제하고 조밀한 군락에서 포화한다. 생성된
`0~1` 농도는 기존 `36×20` 물 수송 격자의 장애물 투과도와 경계 유속을
그대로 사용해 이류·확산하며 반감기 `45초`로 소멸한다. 별도 유체 계산은
하지 않는다.

새우는 현재 위치와 반경 `42`의 8방향 농도를 비교하고 같은 위치의 유속을
읽는다. 유의한 농도 기울기가 있으면 높은 쪽을 주 방향으로 삼고, 냄새가
검출되는 동안 현재의 상류 방향을 약하게 섞는다. 기울기가 평평하지만
흐름이 있으면 상류 주행을 하고, 냄새와 흐름이 모두 불충분하면 원래의
개체별 상관 무작위 배회로 돌아간다. 이 결과는 먼 먹이 셀을 목표로
선택하지 않고 다음에 이동할 표면의 기하 방향만 정한다. 실제 먹이와
섭취량은 표면이 반경 `64` 안에 들어온 뒤 실제 잔량으로 다시 판정한다.
따라서 냄새만 남은 고갈 표면이나 흐름 반대편의 먼 군락을 좌표로 알아내는
레이더가 아니다.
반경 안에 미량 균막이 있더라도 예상 동화량이 그 자리에서의 섭식 대사를
감당하지 못하면 새 목표로 확정하지 않는다. 미량 먹이를 먹을 수 없게
보호하는 하한은 아니며, 이미 도달한 표면에서는 실제 잔량을 계속
섭취한다. 이 구분은 발밑의 흔적 필름이 지속 가능한 군락의 냄새 추적을
영구히 막는 현상을 방지한다.

먹이장과 별도로 준비된 암컷의 국소 교미 단서장을 둔다. 포란 중이 아니고
영양 상태 `0.40` 이상이며 난소 성숙도 `0.82` 이상인 암컷만 방출한다.
교미 접촉은 알 질량을 전부 마련하기 전에 완료될 수 있지만, 현재 brood의
보존 질량이 모두 채워지기 전에는 포란 발생이 시작되지 않는다. 이 장은 같은 `36×20` 흐름을
쓰되 반감기 `18초`로 더 빨리 사라진다. 번식 가능한 성체 수컷만 자기
주변 반경 `42`의 8방향 농도와 유속을 표본화해 배회 방향을 바꾼다.
암컷의 좌표나 ID는 공개되지 않는다. 준비된 암컷도 주변 수컷을 검색하거나
특정 수컷을 목표로 이동하지 않는다. 실제 교미 누적은 자연스럽게 마주친
암수가 `36` 안에 있을 때만 시작하며, 이 안에서 `3초`를 유지해야 한다.

두 냄새장은 산소·탄소·질소·생체량이 아닌 행동 신호여서 닫힌 물질
장부와 수질 화면에는 포함하지 않는다. 각각 `720`칸 농도 배열과 소스
임시 배열만 추가하며, 생태 틱마다 필드별 스칼라 확산 한 번과 최대 한
번의 공통 이류를 계산한다. 저장할 때는 선택 필드로 기록하고 이전
저장에는 `0`으로 복원한다. 이미 도달한 군락의 실제 섭식은 Holling II형
밀도 반응을 따라 미량까지 연속적으로 느려진다. 여러 마리가 같은 셀을
먹으면 요청량을 합산한 뒤 남은 양을 넘지 않도록 비례 배분한다. 먹힌
조류와 균 필름은 화면과 시뮬레이션 생체량에서 실제로 감소한다. 합산 요청이
남은 양 이상이면 규조류·붓뚜껑말·분해균·질산화균의 해당 칸을 정확히
`0`으로 만든다. 미션별 보호 잔량이나 먹을 수 없는 바닥값은 없다.

이 모델은 체리새우 종의 분자별 후각 역치를 재현한다는 뜻이 아니라,
저서성 갑각류가 먹이 화학 단서와 유동 정보를 결합해 냄새 기둥을 찾는
관찰을 수조 격자 해상도에 맞게 압축한 것이다.
교미 단서도 장거리 성페로몬이 체리새우에서 직접 입증됐다고 가정하지
않는다. `N. davidi`의 직접 연구는 고밀도 집단에서 수컷이 개체를
확인하는 순수 탐색과 접촉의 중요성을 강조하고, Caridea 검토도 장거리
성 유인 물질은 흔하지 않고 접촉 화학 신호가 보편적이라고 정리한다.
따라서 현재장은 준비된 암컷 주변의 짧은 국소 힌트이고 실제 교미는
근접 판정으로 남긴 보수적 추론이다.

- 가재의 먹이 화학 단서 방향 결정이 유체 조건에 따라 달라진 결과:
  [Moore & Grills, 1999, DOI 10.1006/anbe.1999.1230](https://doi.org/10.1006/anbe.1999.1230)
- 두 냄새원 배치가 농도 펄스와 가재 탐색 전략을 바꾼 결과:
  [Wolf, Voigt & Moore, 2004, DOI 10.1023/B:JOEC.0000018625.83906.95](https://doi.org/10.1023/B:JOEC.0000018625.83906.95)
- 현장 게 실험에서 성공적인 근원 탐색에 상류 주행과 농도 분포 반응이
  함께 필요했던 결과:
  [Zimmer-Faust et al., 1995, DOI 10.2307/1542075](https://doi.org/10.2307/1542075)
- 갑각류가 유속과 냄새 농도를 함께 표본화할 때 난류 냄새 기둥 탐색에
  유리하다는 수조·CFD 분석:
  [Pravin & Reidenbach, 2013, DOI 10.3390/s131216591](https://doi.org/10.3390/s131216591)
- `N. davidi`의 순수 탐색 체계와 수컷 접촉이 암컷 난소 성숙을
  앞당긴 결과:
  [Tropea et al., 2018, DOI 10.1016/j.zool.2018.08.003](https://doi.org/10.1016/j.zool.2018.08.003)
- Caridea에서 장거리 성 유인 물질은 드물고 접촉 화학 인식이 흔하다는
  검토:
  [Correa & Thiel, 2003, DOI 10.4067/S0716-078X2003000200006](https://doi.org/10.4067/S0716-078X2003000200006)
- 다른 Caridea 종에서 표면 성분을 이용한 접촉 성페로몬 가능성을
  검증한 행동 연구:
  [Caskey et al., 2005](https://academic.oup.com/jcb/article-abstract/25/4/571/2670417)

조류와 균 필름이 같은 표면에 함께 있을 때는 규조류, 붓뚜껑말 `0.72`,
분해균 `0.45`, 질산화균 `0.22`의 실제 잔량 가중치로 섭식 요청을 나눈다.
고정 최소 조류 몫은 두지 않아 거의 사라진 조류가 풍부한 생물막 섭식을
가로막지 않는다. 누적 `새우가 먹은 조류`에는 실제 붓뚜껑말·규조류
감소분만 더한다. 화면의 실 모양·규조류 세부 무늬 수도 현재 생체량
구간에 따라 다시 계산하므로, 먹힌 군락은 내부 수치뿐 아니라 눈에 보이는
밀도도 함께 줄어든다. 별도 섭식 흔적이나 구멍 레이어는 두지 않으며, 현재
남은 생체량이 `0`이면 해당 셀의 막과 세부 무늬도 모두 사라진다.

위 가중치는 표면 선택에만 쓰지 않고 최근 영양 섭취량과 실제 동화량에도
같이 적용한다. 즉 규조류의 기본 동화율은 58%이고 붓뚜껑말·분해균·질산화균은
각각 그 동화량의 `0.72`, `0.45`, `0.22`만 저장 영양으로 들어간다. 나머지는
먹지 않은 것으로 되돌리는 것이 아니라, 실제로 뜯긴 질량 중 소화되지 않은
몫으로 배설 유기물에 남는다.

섭취 질량은 현재 활성 물질 순환에서 다음처럼 나뉜다.

| 경로 | 현재 비율 | 의미 |
|---|---:|---|
| 몸·번식 저장 | 규조류 58%, 다른 먹이는 품질 가중 | 저장량에 들어간 뒤 유지, 성장, 번식에 사용 |
| 고형 배설물 | 실제 섭취량 - 동화량 | 이후 용출되어 분해균 먹이가 됨 |

섭식 순간에 별도의 고정 호흡 몫을 다시 빼지 않는다. 산소 소비와
무기탄소·암모니아 반환은 몸·저장 질량에서 지속 유지대사를 지불할 때만
발생하므로 같은 먹이를 두 번 호흡 처리하지 않는다.

개체는 먹이 부족, 압축 수명 도달, 저산소, 독성 노폐물 누적 또는 극단적인 수온 스트레스에 의해 죽을 수 있다. 사망 시 남은 몸·일반 저장량·번식 저장량만 고형 유기물로 돌아가므로 이미 호흡·배설한 먹이가 사체에서 중복 생성되지 않는다.

영양 상태는 별도의 허기 탱크가 아니다. 먹이의 동화분은 `저장 생체량`에 들어가고 유지 대사와 성장이 이 저장분을 사용한다. 화면의 0~1 영양 상태는 일반 저장 충족도를 72%, 몸 구조의 건전도를 28%로 합성한 파생값이다. 저장 한도는 생애 단계와 관계없이 그 개체가 실제로 달성한 구조 생체량의 6%, 지급 성체의 초기 저장량은 구조량의 1.5%로 제한한다. 따라서 구조량 `0.082 B`인 치새우는 `0.00492 B`, `0.20 B`에서 성숙한 수조 출생 성체는 `0.012 B`, `1.0 B` 지급 성체는 `0.06 B`까지만 저장한다. 이전 치새우의 고정 `0.09 B` 저장고와 고정 `0.024 B` 성장 하한은 작은 개체가 몸 질량의 상당 부분을 숨은 먹이로 쌓게 했으므로 제거했다. 치새우는 현재 영양 상태가 양호하더라도 성숙 구조량 `0.20 B`에 못 미치면 실제 성장 재료를 얻기 위한 섭식을 계속한다. 그 스텝에서 성장시킬 수 있는 양만 저장 상한 위로 잠시 통과시키고 곧 구조 질량으로 옮기므로, 성장 욕구를 큰 장기 비축분으로 대신하지 않는다. 저장량이 고갈되면 성체는 달성한 구조 질량의 1%, 치새우는 5%까지만 유지대사에 사용한 뒤 아사한다. 따라서 먹이가 끊기면 성장과 번식이 먼저 멈추고 개체수 감소가 뒤따르되, 숨은 저장량 때문에 한 세대 가까이 늦어지지 않는다.

치새우의 기본 구조 성장률은 각 개체의 `648~1,080`초 성숙 일정에서 계산한다. 먹이 부족으로 실제 구조 성장이 일정보다 뒤처진 경우에만 부족분에 비례해 성장 상한을 연속적으로 높이며, 최대값은 기본의 `2.5배`다. 이 보상 성장은 현재 스텝에서 실제로 동화한 저장 질량만 구조로 옮기므로 수명, 먹이, 성숙 질량을 보정하지 않는다. 일정대로 자란 개체의 배율은 항상 1이다.

알 물질과 성체 후속 성장을 배분할 때는 달성 구조량의 1.2%를 일반 저장으로
보호한다. 이는 저장 상한의 20%이고, 화면 영양 상태 `0.424`에 해당해 암컷
교미선 `0.40`보다 조금 높다. 이전 0.8% 보호량은 영양 상태 `0.376`밖에
되지 않아, 암컷이 brood 질량을 다 마련해 추가 섭식을 끝내는 순간 교미
자격도 잃는 모순을 만들었다.

성체 암컷은 고정 휴지기 대신 개체별 `난소 성숙도`를 가진다. 성숙도는
수온·건강·현재 영양 상태에 따라 연속적으로 진행하며 한 주기는
`140~240초` 범위에서 개체와 반복 산란 차례마다 결정된다. 영양 상태
`0.32~0.44`와 최근 실제 섭식량 사이에서 속도가 연속적으로 달라지며,
조건이 부족하면 멈췄다가 먹이가 다시 생긴 뒤 같은 지점에서 이어진다.
따라서 같은 날 태어난 개체도 모두 한 시각에 성숙하거나 출산하지 않는다.
비포란 암컷은 알 질량과 난소 성숙도 중 하나라도 아직 부족하면 일반 포만
종료선만으로 먹이 탐색을 끝내지 않는다. 이는 특정 성비나 개체수를 보고
먹이를 지급하는 보정이 아니라, 해당 암컷이 실제 먹이를 더 섭취해야 진행할
수 있는 개체별 번식 비용이다.

현재 brood의 물질은 포란 중 잠겨 있지만 다음 난소의 성숙도는 별개로
진행할 수 있다. 실제 장기 사육에서 일부 암컷의 난소 재성숙이 포란 중 거의
완료됐고, 210일 동안 35%가 6회 이상 산란한 관찰을 반영한 것이다. 다음 알
질량은 현재 brood가 부화한 뒤에만 새로 이전하므로 두 brood의 물질을 같은
저장고에서 중복 사용하지 않는다.

난소 성숙도와 알의 질량은 서로 다른 조건이다. 알의 질량은 일반 저장량 중
생존 비축분을 넘는 부분에서만 **번식 저장 생체량**으로 옮긴다. 난소가
성숙한 암컷은 국소 접촉을 먼저 마칠 수 있지만, 그 개체가 현재 주기 시작에
고정한 두 대표 개체분의 보존 질량이 전부 없으면 포란은 시작하지 않는다. 질량이
충분해도 난소가 덜 성숙하면 기다린다. `최근 8초 안에 먹었는가` 같은
이산적인 통과 조건은 사용하지 않고 실제 최근 섭식량에 따라 진행 속도만
연속적으로 바꾼다. 짧은 먹이 파동이 수조의 모든 암컷을 한 시계로 맞추는
현상을 피하면서도 번식 비용은 계속 실제 섭취 물질로 지불한다.

난소 진행이 최대 속도에 도달하는 최근 섭취량도 모든 암컷에 같은 절대값을
쓰지 않는다. `8 × (그 개체의 현재 유지대사 + 최대 알 질량 이전률) / 0.58`
로 계산한다. 현재 보통 수조 출생 암컷은 약 `0.0024 B`, 지급 성체는 약
`0.0029 B`이며 실제 섭취량이 이보다 낮으면 속도가 비례해 줄어든다. 이전
고정 `0.0048 B`는 구조량 `0.2 B`인 작은 암컷에도 `1.0 B` 성체 수준의
절대 섭취를 요구해, 조류가 `50~68 B` 남은 후기에도 난소 준비만 지연시키고
개체군을 9마리까지 떨어뜨렸다. 현재 식은 몸 크기와 실제 알 이전 비용만
보며 전체 새우 수나 조류 총량은 입력으로 받지 않는다.

지급 암컷은 자연 집단의 번식 단계 차이를 압축해 `0.18~0.78` 범위의
서로 다른 난소 성숙도를 가진다. 시작 번식 질량도 해당 암컷의 2마리 brood
질량 `0.035 B`에 그 성숙도를 곱한 만큼만 함께 지급한다. 이는 무료로 생긴
새끼가 아니라 지급 개체의 초기 총질량에 포함된 물질이며, 나머지는 실제
섭취·동화 뒤 저장량에서 채워야 한다. 난소 성숙도가 1에 도달해도 암컷은
수컷을 직접 검색하거나 뒤쫓지 않는다. 번식 가능한 수컷만 준비된 암컷이
만든 국소 단서의 농도 기울기를 따라 배회하며, 실제 거리가 `36` 안에서
`3초` 유지될 때 포란을 시작한다. 포란 질량은
유지 대사와 분리해 보존하며, 모체의 건강과 영양 상태가 안전한 동안
수온에 따라 `68~82초` 발생한 뒤 실제 새끼 몸 질량으로 이전한다.
수조 전체에서 먹이나 짝을 검색하는 전역 판정은 사용하지 않는다. 이 구조는
섭취물을 reserve·structure·reproduction buffer로 나누는 단순화된 동적
에너지 예산(DEB) 원칙을 따른다.

수온은 한 개의 만능 계수가 아니라 세 경로로 나뉜다.

```text
대사·산소 요구량 = 24°C 기준량 × 1.07^(현재 수온 - 24)
성장·번식 진행 = 먹이 조건을 만족한 시간 × 종별 번식 수온 곡선
수온 건강 피해 = 1 - 종별 생존 적합도
```

대사 보정은 극단값에서 수치 폭주가 나지 않도록 `0.55~1.65`로 제한한다. 번식 곡선은 `20°C:0.78, 24°C:1.0, 28°C:1.08, 32°C:0.28, 33°C:0`의 핵심점을 사용한다. 이는 20·24·28°C에서 높은 생존을 보이되 낮은 온도에서 대사·번식이 느려지고, 33°C에서 산란이 억제되었다가 28°C 복귀 뒤 회복된 연구 관계를 게임 시간에 맞게 압축한 것이다. 성비는 수온으로 바꾸지 않는다.

### 5.3 게임 보정과 한계

- 실제 개월 단위 생활사를 출생부터 `1,800~3,000` 시뮬레이션초로 압축한다.
  어린 단계도 굶주림·수질 스트레스에 의해 죽을 수 있고, 성숙했다고 전체
  수명 시계를 다시 시작하지 않는다.
- 실제 산란 수를 그대로 화면 개체 수로 만들지 않고 한 번의 포란을
  2~3마리의 실제 추적 개체를 낳는다. 성적 성숙 크기의 작은 암컷은
  2개, 먹이를 실제로 동화해 충분히 커진 암컷은 3개를 보존 질량으로
  먼저 마련한다. 한 brood를 시간차로 쪼개지 않으며 해당 개체분의 보존
  질량을 어미가 먼저 마련해야 하므로 저밀도 보정으로 공짜 출생시키지 않는다.
- 각 대표 자손의 성별은 독립적인 50:50 결정으로 생성한다. 개체군 평균은
  1:1에 가깝지만 각 brood를 강제로 암수 짝짓지 않으며, 작은 개체군의
  성비 편중과 번식 단절도 실제 생태 위험으로 남겨 둔다.
- 새 수조를 시작할 때만 생물학적 실행 시드를 새로 뽑는다. 따라서 같은
  배치라도 작은 brood의 성비와 개체 변이는 실행마다 달라질 수 있다.
  저장·불러오기에는 이 시드를 함께 보존해 이미 태어난 계통이나 이후의
  추첨 결과가 불러올 때마다 바뀌지 않게 한다.
- 현재 주 먹이는 두 조류이고 두 균 기능군도 더 낮은 가중치의 생물막 먹이로
  포함한다. 현실의 균류·원생생물·찌꺼기를 모두 별도 먹이로 구분하지 않는다.
- 저산소 시작값 `30`, 독성 시작값 `6`은 mg/L가 아닌 게임 농도다. 실제 사육 안전값으로 인용하면 안 된다.
- 20~28°C의 상대 관계는 연구와 맞추되 곡선 중간값과 피해 속도는 압축 수명에 맞춘 게임 보정이다.
- 33°C에서 번식이 억제된다는 근거를 사망 문턱으로 오해하지 않는다. 직접 수온 피해는 더 넓은 생존 곡선에서 누적한다.
- 온도 의존 성비는 근거의 재현성과 작은 개체군 안정성을 고려해 현재 모델에 넣지 않았다.

이전 고정 휴지기 모델의 미션 5 장주기 수치는 현재 생애 규칙의 합격 근거로
재사용하지 않는다. 현재 자동 검증은 미션 지급량 그대로 조류 각 8회와
균 기능군 각 4회를 처음에만 접종하고, 3,600초에 지급 새우 4마리를 한 번
방류한 뒤 추가 먹이 없이 계속한다. 일반 11,000초 회귀 검사는 초기 조류층,
지급 개체가 모두 교체된 3세대 군집, 두 균 기능군과 닫힌 물질 장부를 빠르게
확인한다. 별도 40,000초 전용 검증은 희귀한 단일 성별 계통 실패와 순환
자체의 실패를 섞지 않도록 명시한 기준 실행 시드 `1`을 사용한다. 플레이의
새 수조는 계속 무작위 실행 시드를 사용한다. 장기 검증은 14,400초 이후
새우가 18마리 아래로 떨어지지 않고 160마리를 넘지 않는지, 24,000초 이후
조류·암모니아·영양염 및 분해균·질산화균이 실제로 하강과 반등하는지
검사한다. 생산자 저점은 임의의 절대값이 아니라 초기 총 접종량 `1.92 B`의
4배인 `7.68 B`보다 높아야 하며, 저점 뒤 `2 B`와 5% 중 큰 값 이상 실제로
반등해야 한다. 현재 기준 궤도의 600초 표본에서는 18세대, 새우 `25~54마리`,
후기 생산자 `37.28~43.23 B`, 후기 질산화군집 `0.290~0.317 B`를 확인했다.

### 5.5 큰물벼룩의 개체·행동·압축 생애

큰물벼룩은 농도장의 대표 점이나 화면 장식이 아니라 나이·세대·구조
생체량·저장량·번식량·위치·속도를 가진 개별 개체다. 보유 목록에서 한
마리를 배치하면 계산 개체와 화면 개체가 각각 한 마리씩 생기며, 출산도
태어난 새끼 각각을 별도 추적 개체로 추가한다. 물벼룩 생체량을 별도 개체군 농도장에
중복 보유하지 않는다.

화면 배율·선택 반경과 대량 사망 때의 사체 표시 수 제한은 표현 계층이다.
이 값들은 개체 질량, 섭식, 생존, 번식, 사체 물질과 사망 통계를 바꾸지
않으며 화면의 한 물벼룩을 여러 계산 개체로 합치지도 않는다.

이동은 다음의 국소 정보만 사용한다.

```text
먹이: 현재 몸이 통과하는 셀에서만 여과
수질 회피: 현재 셀과 반경 42의 인접 8방향만 비교
항상: 7초 단위 상관 배회 + 평균 상승량을 제거한 도약 + 약한 침강
      + 물기둥 중앙 복귀 + 실제 물 흐름 + 벽 반사
```

따라서 멀리 있는 최고 농도 셀이나 수조 전체 군락 목록을 읽는 전역
레이더는 없다. 먹이 방향을 표본화하지도 않으며, 상관 배회와 물 흐름으로
먹이 셀을 만났을 때만 여과한다. 산소·독성 회피만 몸 주변의 짧은 범위에서
작동한다. 현재 셀의 먹이가 풍부하면 배회 속도를 낮춰 그 물덩어리에 더
오래 머물고, 먹이가 부족하면 같은 확률적 방향을 유지한 채 탐색 활동만
늘린다. `D. magna`와 `D. pulex`가 조류 배양수의 방향을 고르지는 않았지만
고농도 조류에서 유영 속도를 낮춘 실험을 따른 단순화다. 다른 물벼룩
교잡종에서 먹을 수 있는 조류 관련 냄새를 선택한 결과도 있으므로 모든
물벼룩 종에 먹이 화학주성이 없다고 일반화하지는 않는다. 다만 이 미션의
큰물벼룩에는 먼 냄새원을 직접 추적하는 농도장보다 국소 체류시간 반응을
사용한다.

- 큰물벼룩·물벼룩의 조류·경쟁자·포식자 냄새 반응:
  [Roozen & Lürling, 2001, DOI 10.1093/plankt/23.8.797](https://doi.org/10.1093/plankt/23.8.797)
- 먹을 수 있는 조류 관련 냄새에 대한 종·교잡종 차이:
  [Van Gool & Ringelberg, 1996, DOI 10.1093/plankt/18.2.197](https://doi.org/10.1093/plankt/18.2.197)

현재 개체별 압축 수명은 `750~1,550초`다. 어린 개체는 개체별 `4~6회`
탈피 목표와 실제 구조 질량 조건을 모두 만족해야 성체가 된다. 성체의
탈피 기준 주기는 `150초`이며 개체·탈피 차례마다 기준의
`0.82~1.18배`로 달라진다. 배아 발생 기준은 `110초`지만 타이머가
끝났다고 즉시 태어나지 않고 다음 성체 탈피에서만 brood가 방출된다.
체리새우의 `1,800~3,000초`보다 짧은 상대 순서를
유지하되 실제 일수를 게임 초로 환산하지 않는다. 먹이가 충분해도 창시자가
영구 생존하지 않으며, 후속 세대가 자연사를 대체해야 군집이 유지된다.
먹이·수온·수질은 성숙과 번식 준비, 저장량과 건강에 계속 영향을 준다.

#### 개체 물질 규모

물벼룩 한 번 배치는 계산 개체와 화면 개체를 정확히 한 마리씩 만든다.
지급 성체는 구조 생체량 `0.009375`와 지급 비축량 `0.0012`를 합친
게임 물질 `0.010575`로 시작한다. 체리새우 지급 성체의 구조 `1.0`과
비축 `0.08`을 합친 `1.08`과 비교하면 약 `1/102`다. 따라서 같은
닫힌 수조 물질로 새우보다 수십 배 많은 물벼룩을 지탱할 수 있지만, 화면의
한 마리를 여러 계산 개체로 숨기지는 않는다.

이 비율은 **게임 장부의 상대 규모**다. US EPA 자료의 물벼룩 건중량과
체리새우 연구의 체중은 종, 성별, 생활 단계, 사육 조건과 건중량/습중량
기준이 서로 달라 곧바로 나눌 수 없다. `1/102`를 실제 건중량 대 습중량의
정밀 환산값으로 주장하지 않으며, 문헌의 크기 차이와 FAO의 리터당
수십 개체 사육 범위를 반영한 뒤 게임 수조의 생산량·장부·표시 밀도로
검증하는 보정값으로 사용한다.

몸 물질이 약 `1/102`라고 해서 한 개체의 순간 섭식량도 항상 정확히
`1/102`이라는 뜻은 아니다. 개체 물질과 여과량은 전 생애에 걸친 연속
곡선으로 별도 계산한다. 절대 물질 소비는 실제 셀에서 인출한 양으로 장부에
기록하고, 여러 마리가 유지되는지는 한 개체 환산이 아니라 장주기 수조 전체
생산·소비량으로 판정한다.

#### 연속 여과와 질량으로 지불하는 번식

유생과 성체는 단계가 바뀌는 순간 섭식량이 튀지 않도록 같은 연속 체질량
곡선을 사용한다. 한 시뮬레이션 구간의 계산 구조는 다음과 같다.

```text
유효 여과 규모 = 전 생애 공통 연속 함수 f(현재 개체 물질)
먹이 요청량
= 유효 여과 규모 × 최대 여과율 × 국소 먹이 기능반응 × Δt
```

따라서 어린 개체는 절대 여과량이 작고, 성숙 순간 단계 라벨 때문에
여과량이 튀지 않는다. 전 생애 질량 지수는 `0.75`이며, 실제로 셀에서
빠진 양만 섭식으로 인정한다.
실제로 같은 셀에서 인출된 식물플랑크톤만 고품질 먹이로 동화된다. 유지
대사를 뺀 현재 순잉여,
모체의 유지 비축분, 번식 저장고 여유와 실제 번식 저장 질량이 차례로
확인되며, 어린 한 마리마다 `0.00075`가 모체 번식 저장고에서 빠진다.
한 번의 포란은 완전히 지불된 어린 `1마리`를 만든다.
주변 농도가 높다는 이유만으로 알이나 새끼 질량을 무료로 만들지 않는다.

성체는 현재 brood의 잠긴 배아 질량과 다음 brood 한 번분의 난소 물질만
보유할 수 있다. 배아가 발달하는 동안 다음 난소를 마련할 수는 있지만,
식물플랑크톤 먹이 반응이 기준 아래로 떨어지면 새 질량 배분은 멈춘다.
탈피 때 발달이 끝난 brood를 먼저 방출하고, 실제로 지불된 다음 brood가
있으면 그때 육방에 넣는다. 이 구조는 모든 개체에 무작위 출산 지연을
덧붙이는 방식이 아니라 갑각류의 탈피–육방 주기 자체로 세대 시점을
분산한다.

기존 `4,800초` 고정 시드의 최종 개체 수와 이전 모델에서 얻은
`7,200/14,400초` 밀도 범위는 현재 모델의 합격 근거에서 제외한다. 현재
게이트는 서로 다른 fixture의 후반 창에서 물벼룩 최저 `15마리`, 평균
`30마리`, 최종 `20마리` 이상과 새우 최저 `4마리`를 요구하고,
창시자가 아닌 후속 세대의 출생·성숙이 계속되며, 살아 있는 2세대 이상과
식물플랑크톤의 고갈 뒤 회복이 함께 나타나는지를 요구한다. `1,000마리`는
생태적 수용량이나 게임 상한이 아니라 수천 마리로 치닫는 폭증 경보다. 검사 수치는
계산에 개입하지 않으며 자동 보충이나 개체 수 하드 캡도 없다. 큰 수조의
송사리 포식 부하는 아직 별도 미검증이다.

참고 근거:

## 6. 분해균·질산화군집 모델과 근거

### 6.1 기능군으로 나누는 이유

현재 모델은 미생물을 실제 종 이름으로 고정하지 않고 두 기능군으로 나눈다.

1. **종속영양 분해자 필름**: 유기물과 산소를 사용하고, 일부를 새 필름으로 고정하며 나머지를 무기탄소와 암모니아성 질소로 돌린다.
2. **통합 질산화 필름**: 암모니아성 독성 노폐물과 산소를 사용하고, 일부를 새 필름으로 고정하며 나머지를 영양염으로 바꾼다.

실제 수조의 질산화는 암모니아 산화 세균·고세균, 아질산 산화 미생물과 완전 암모니아 산화 `comammox` 등 여러 구성원이 담당할 수 있다. 따라서 도감의 `질산화균`은 특정 한 종이 아니라 게임의 통합 질산화군집이라는 점을 명시한다.

#### 생활형 용어

현실의 분해자와 질산화 미생물은 `표면에 붙는 종 / 물에 뜨는 종`으로 완전히
갈라지지 않는다. 같은 수계에 다음 상태가 함께 존재한다.

| 용어 | 뜻 | 현재 게임 처리 |
|---|---|---|
| 분해자 필름 | 바닥·돌·수초·입자 표면에 붙어 유기물을 처리하는 종속영양 미생물 군집 | 표면 셀별 활성 생체량으로 계산 |
| 질산화 필름 | 표면 생물막에서 암모니아 산화·아질산 산화·완전 질산화를 수행하는 통합 군집 | 표면 셀별 활성 생체량으로 계산 |
| 부유 분해자 | 물기둥에서 자유생활하거나 작은 입자에 붙어 용존·입자 유기물을 처리하는 미생물 | `36×20` 활성 농도장으로 계산 |
| 부유 질산화군집 | 물기둥 또는 떠 있는 미세 입자·필름 조각에 포함된 질산화 미생물 | 활성 군집으로는 아직 계산하지 않음 |
| 수중 전파체 | 표면 필름에서 떨어져 흐름을 타고 다른 표면을 다시 식민화할 수 있는 생체량 | 분해균은 공간 농도장, 질산화균은 수조 전체 압축 저장량으로 계산 |

현재 분해자는 두 생활 위치를 모두 계산한다. 표면 필름에서 떨어진 실제
생체량은 같은 위치의 부유 분해균장으로 이동하고, 물 흐름을 따라 이동하면서
유기물·산소를 사용해 성장·무기화·사멸한다. 큰물벼룩은 같은 물 셀의 부유
분해균만 낮은 효율로 여과한다. 질산화균은 현 단계에서 표면 반응을 중심으로
유지하며 탈락분만 비공간 전파체로 압축한다.

표면 필름과 부유 군집을 같은 수치로 합치지 않는다.
부착·이탈·사멸·수송으로 실제 생체량을 이동시키고, 어느 상태에서 처리했는지
관찰 정보에 분리해 표시한다.

### 6.2 현재 구현

두 기능군은 먹이와 산소가 모두 필요하다는 이중 Monod형 제한을 사용한다.

```text
활동도
= 먹이 / (먹이 + 먹이 반포화값)
 × 산소 / (산소 + 산소 반포화값)

처리량
= 필름량 × 최대 처리율 × 활동도 × 수온 보정 × dt

성장
= 실제 처리량 × 생체 전환율 × 빈 표면

사멸
= [유지 사멸 + 기아 사멸 × (1 - 실현 활동도)] × 수온 보정

수온 보정
= 1.08^(현재 수온 - 24°C)
```

현재 주요 상대 관계는 다음과 같다.

- 분해자는 유기물 펄스에 빠르게 증가하고 먹이가 줄면 빠르게 감소한다.
- 질산화군집은 더 느리게 성장하지만 낮은 부하에서 더 오래 유지된다.
- 두 군집 모두 산소가 부족하면 처리와 성장이 줄어든다.
- 같은 표면 공간을 공유하고 과밀하면 일부가 떨어져 고형 유기물이 된다.
- 인접 표면 확산과 작은 수중 방출·재정착을 통해 떨어진 표면으로도 천천히 전파된다.

현재 반응 상수는 다음과 같다. 모두 게임 농도와 시뮬레이션초에 맞춘 상대값이다.

| 기능군 | 먹이 반포화 | 산소 반포화 | 최대 처리율 | 생체 전환율 | 유지/기아 사멸률 | 산소 수지 | 표면 전파율 |
|---|---:|---:|---:|---:|---:|---|---:|
| 분해자 | 4 | 14 | 0.02 | 0.42 | 0.0002 / 0.0016 | 실제 무기화된 유기탄소에만 부과 | 0.0035 |
| 통합 질산화군집 | 0.8 | 24 | 0.002 | 처리 N의 0.035 | 0.00006 / 0.0001 | 실제 질산염 생성과 균체 탄소 고정을 함께 계산 | 0.00045 |

24°C의 최대 균체 순증가율은 빈 표면에서 분해자 약 `0.0082 B/B/s`,
질산화군집 약 `0.000815 B/B/s`이므로 전자는 약 10배 빠르다. EPA WASP가
질산화와 용존 유기질소 무기화에 사용하는 `θ=1.08`의 형태와 상대 온도
민감도를 적용하되, 게임의 초 단위 처리율 자체를 실제 일 단위 상수로
주장하지 않는다. 먹이·산소가 같아도 차가운 표면에서는 증식·사멸·전환이
함께 느리고 따뜻한 표면에서는 빨라진다.

질산화군집의 반포화값 `0.8`과 최대 섭취율 `0.002`는 미션 5의 표시
암모니아 범위에서 큰 농도 급등을 기다리지 않고 반응하되, 고농도 펄스를
순간 소거하지 않게 한 압축 보정이다. 산소가 충분하고 표면에 빈자리가 있는
조건에서 순성장 전환점은 암모니아 약 `0.5~0.8`에 놓인다.

질산화군집이 먹이를 전혀 처리하지 못할 때 유지·기아 감쇠를 합친 반감기는
약 `4,330초`다. 이는 수 주 기아 뒤에도 빠르게 재활성화되는 부착
`Nitrosomonas`의 정성적 생존 특성을 게임 세대 시간으로 압축한 값이며,
최저 생체량 보장이나 절멸 방지 조건은 아니다.

분해자와 질산화군집의 수중 이탈률은 각각 `0.00012`, `0.00007`, 부유 상태
사멸률은 각각 `0.0035`, `0.0007`이다. 질산화군집의 인접 셀 차이는 현재
약 `1,540초`마다 절반으로 줄지만, 떨어진 표면의 식민화는 이 값이 아니라
수중 이탈·재정착 경로도 함께 담당한다. 따라서 표면 전파율을 크게 올리면
좋은 자리에서 나쁜 자리로 필름을 평탄화할 뿐 총생체량을 만들지는 않는다.
같은 초기조건의 `0.00045 / 0.0008 / 0.0012 / 0.002` 비교에서는 12,000초 뒤
질산화군집 총량이 각각 `0.1746 / 0.1754 / 0.1607 / 0.1655 B`였다. 두 배에
가까운 `0.0008`도 총량을 의미 있게 늘리지 못했고 더 빠른 값은 오히려 줄어,
현재값을 유지한다. 관찰용 셀 농도 문턱은 검증 편의를 위한 값일 뿐, 그보다
얇은 실제 필름을 죽거나 없는 것으로 취급하지 않는다.

### 6.3 게임 보정과 한계

- 반포화값·처리율·수율은 실제 mg/L 또는 일 단위 상수가 아니라 압축 게임 농도에 맞춘 값이다.
- 암모니아→아질산→질산의 두 단계를 `toxicWaste → nutrients` 한 단계로 묶는다.
- 부착조류는 `toxicWaste`의 암모니아성 질소와 `nutrients`의 산화된 무기질소를
  모두 직접 사용할 수 있다. 따라서 질산화군집이 없다는 이유만으로 조류의
  암모늄 흡수를 막거나 즉시 절멸시키지 않는다. 질산화군집의 기능은 암모니아성
  독성 풀을 산화된 영양염 풀로 바꾸어 부하 변동을 완충하는 것이다. 규조류의
  직접 암모늄 흡수는 [Nitzschia sp. 연구](https://pubmed.ncbi.nlm.nih.gov/28162247/)와
  [Nitzschia ovalis의 질소원 흡수 연구](https://www.sciencedirect.com/science/article/pii/0022098186901279)를 따른다.
- 생산자와 질산화군집은 한 생태 스텝이 시작할 때 존재한 같은 암모니아장을
  보고 각각 실제 빛·먹이·산소 제한을 반영한 요청량을 만든다. 셀별 암모니아가
  부족하면 요청량에 비례해 나누며 어느 한쪽에 숨은 최저 보장량이나 코드 실행
  순서 우선권을 주지 않는다. 빛이 계속 강하고 조류막이 큰 환경에서는 조류가
  암모늄 경쟁에서 질산화군집을 실제로 억제할 수 있다. 이는 조류가 있는
  퇴적물에서 암모니아 산화균의 잠재 활성이 20% 미만으로 떨어진 실험과
  일치한다([Risgaard-Petersen et al., 2004](https://pmc.ncbi.nlm.nih.gov/articles/PMC520845/)).
- pH, 알칼리도, 규산염, 인산염, 혐기성 분해와 탈질은 계산하지 않는다.
- 필름 내부의 산소·기질 침투 깊이는 풀지 않고 주변 반경 수질과 하나의 산소 제한항으로 압축한다.
- 미생물 종 조성과 천이는 표시하지 않고 기능군 생체량만 보여준다.
- `θ` 보정은 배포본의 정상 수온 범위를 위한 반응속도 근사다. 극단적인 고온에서 실제 군집이 붕괴하는 종 조성 변화까지 풀지 않는다.

## 7. 산소·탄소·질소 물질 장부

### 7.1 현재 구현 원칙

현재 미션 5·6과 실험실은 빛 에너지만 외부에서 받고 물질은 닫힌 단순계로 다룬다.

```text
무기탄소 + 무기질소
→ 조류 생체량 + 산소
→ 새우 몸·배설물·호흡 산물
→ 고형·용존 유기물
→ 분해균 성장 또는 호기성 무기화
→ 암모니아성 노폐물
→ 질산화군집 성장 또는 질산화
→ 영양염
→ 다시 조류
```

모든 생물과 유기물은 게임용 고정 C:N 조성을 공유한다. 이 비율은 실제 모든 생물의 원소 조성이 같다는 주장이 아니라, 섭식·배설·사망 과정에서 질량이 이중 생성되거나 사라지는지를 감사하기 위한 압축 장부다.

물속 무기탄소와 공기층 CO₂, 용존산소와 공기층 O₂는 각각 유한한 저장고 사이에서만 교환한다. 물속 무기탄소는 `36×20` 공간장이므로 조류·질산화균 주변의 국소 탄소 소비와 공통 물 흐름에 따른 이동이 나타난다.

현재 장부는 생체량 `1.0`에 질소 `0.08`, 탄소 `0.32`를 대응시킨다. 고정·무기화되는 유기탄소 `1.0`당 산소 등가량 `1.12`를 양방향에 똑같이 사용한다. `1.12`는 게임 표시 단위의 환산척도이며 더 이상 장기 실행을 맞추기 위해 생산 쪽에만 더한 여유 계수가 아니다.

질산화의 산소 등가량은 독립 보정값으로 맞추지 않는다. 탄소 산화의 실제 질량비 `32/12 g O₂/g C`와 암모니아성 질소 산화의 `64/14 g O₂/g N` 비율로부터 다음처럼 유도한다.

```text
qC = 1.12
qN = qC × (64/14) ÷ (32/12) = 1.92
```

전체 반응은 상태 벡터 `x`, 화학량론 행렬 `S`, 반응속도 `v`에 대해 다음 형태로 해석한다.

```text
dx/dt = S · v(x)
```

반응속도는 광량·수온·먹이·산소·표면 공간에 따라 달라지지만, 각 반응 열은 탄소·질소와 아래 산소 등가 불변량을 보존해야 한다.

```text
E = (물속 산소 + 공기층 산소)
    - qC × 전체 유기탄소
    + qN × 질산염성 영양질소
```

닫힌 수조 내부 반응과 물–공기층 재분배만 있을 때 `E`의 변화는 수치 허용오차 안에서 0이어야 한다.

#### 생산자

생산자가 무기탄소 `Cfixed`, 질산염성 질소 `Nnitrate`를 새 생체량으로 고정할 때:

```text
O₂ 생산 = qC × Cfixed + qN × Nnitrate
```

암모니아성 질소는 이미 생물체 질소와 같은 환원 상태로 압축하므로 추가 `qN` 항이 없다. 질산염은 생물체 질소로 환원할 때 1 mol N당 8전자, 즉 2 mol O₂에 대응하는 광합성 전자 흐름이 필요하므로 산소 **등가량**을 더한다. 이는 질산염 흡수 시 별도 산소 기포가 즉시 보인다는 뜻이 아니라, 생략한 전자전달계를 닫는 장부 항이다.

생산자 호흡은 정확히 반대다.

```text
O₂ 소비 = qC × 실제 무기화 탄소
```

산소가 부족하면 수행 가능한 호흡량만 생체량에서 빠진다. 요청했지만 수행하지 못한 호흡량을 생체량에서 먼저 제거하지 않는다.

#### 새우

섭식은 유기탄소의 소유권을 바꾸는 과정이다. 동화된 몫은 몸과 번식 저장량, 배설된 몫은 찌꺼기로 이동하며 이 이동 자체에는 산소를 부과하지 않는다. 실제 호흡으로 유기탄소가 무기탄소가 된 몫에만 `qC`를 적용한다. 산소가 부족해 호흡하지 못한 먹이 몫은 삭제하지 않고 유기 찌꺼기에 남긴다. 사망 역시 남은 몸 질량을 찌꺼기로 옮길 뿐 즉시 산소를 소비하지 않는다.

#### 분해균

유기물 섭취량 `U`, 실제 균 성장량 `G`라면:

```text
실제 무기화량 = U - G
O₂ 소비 = qC × biomassCarbon × (U - G)
```

이전 구현은 `U` 전체에 산소를 부과했다. 균체로 남은 `G`가 나중에 죽어 다시 분해될 때 산소가 또 부과되어 같은 탄소가 경로에 따라 이중 과금되는 문제가 있었다. 현재는 실제 무기탄소가 된 몫에만 부과한다.

#### 질산화군집

처리한 암모니아성 질소 `Nprocessed` 중 새 균체에 남은 질소를 `Nretained`, 생성한 질산염을 `Nnitrate`, 고정한 균체 탄소를 `Cfixed`라 하면:

```text
Nnitrate = Nprocessed - Nretained
O₂ 소비 = qN × Nnitrate - qC × Cfixed
```

균체로 동화된 질소에는 질산화 비용을 부과하지 않으며, 암모니아 산화에서 얻은 환원력이 균체 탄소 고정에 저장된 몫도 차감한다. 계산 결과는 음수가 되지 않도록 제한한다.

#### 동시 반응과 수치 정밀도

균 반응은 한 기능군이 같은 스텝에서 방금 만든 산물을 다음 기능군이 즉시 먹지 않도록 두 단계로 처리한다.

1. 모든 필름이 반응 전 농도장에서 처리 요청량을 계산한다.
2. 기질·산소·무기탄소 인출 장부와 생성물 수용 장부를 분리해 제한한 뒤 한꺼번에 반영한다.

표면 셀 배열 순서를 뒤집어도 같은 결과가 나오는 회귀 시험을 둔다. 보존 농도장은 장시간 반복 반올림을 막기 위해 `Float64Array`를 사용하며, 화면용 스냅샷에서만 일반 숫자 배열로 복사한다.

미션 5의 초기 물속 무기탄소는 `58`, 닫힌 공기층 CO₂ 저장고는 `22`이며 공기층 산소는 시나리오 초기 산소와 같은 값으로 시작한다. 이 값들은 실제 몰수나 mg/L가 아니라 여러 세대 동안 순환을 관찰하기 위한 보정값이다.

### 7.2 현재 수온–산소 기체 교환

실제 물은 온도가 높아질수록 일반적으로 산소 용해도가 낮아진다. 현재 구현은 수면과 맞닿은 첫 행의 평균 수온을 USGS가 채택한 Benson–Krause 담수 산소 용해도 식에 넣는다.

```text
DOsat(T) = exp(
  -139.34411
  + 1.575701×10^5 / K
  - 6.642308×10^7 / K²
  + 1.243800×10^10 / K³
  - 8.621949×10^11 / K⁴
)

상대 물쪽 용량 S(T) = DOsat(T) / DOsat(24°C)
물속 평형 산소 = (물속 산소 + 공기층 산소) × S / (1 + S)
```

`DOsat` 값만 mg/L이며 게임의 용존산소 `0~100`을 mg/L라고 부르지 않는다. 24°C에서 기존 물/공기층 1:1 분배를 보존하고, 차가워지면 같은 총산소 중 물쪽 몫이 커지며 따뜻해지면 공기층으로 이동한다. 이동량은 수면 셀에만 더하거나 빼고 반대 저장고에 같은 양을 기록하므로 온도가 산소를 생성·삭제하지 않는다.

물속 무기탄소는 용존 CO₂만이 아니라 pH를 생략한 완충 무기탄소 저장고다. 따라서 탄산 평형을 풀지 않은 상태에서 전체 무기탄소에 CO₂ Henry 상수를 직접 적용하지 않고 기존의 약한 물–공기층 교환을 유지한다.

또한 광합성은 산소를 만들고 호흡·유기물 분해·질산화는 산소를 소비한다. 물 흐름과 난류 혼합은 이렇게 생성·소비된 산소를 다른 위치로 운반한다. 현재 공통 유동장은 생물 반응의 크기를 대체하지 않고 반응 산물의 이동 경로를 제공한다.

## 10. 관찰 UI에 공개해야 할 값

모델이 물리적으로 그럴듯해도 플레이어가 원인을 볼 수 없으면 게임 규칙으로 기능하지 못한다. 현재 관찰 지도에는 다음 범위가 연결되어 있다.

- 위치별 수온과 수조 평균·최저·최고 수온
- 선택 위치의 유속 방향과 상대 속도
- 선택한 수질의 농도, 최근 증가·감소 및 주요 원인
- 수조 전체 질소·탄소·산소 등가 장부와 기준 대비 상대 오차
- 선택한 새우의 현재 수온, 대사·번식 수온 보정, 생존 적합도
- 선택 표면의 두 균 기능군 수온 보정과 수온이 반영된 예상 순성장률
- 수면 수온, 1기압 담수 산소 포화도, 닫힌 계의 현재 물쪽 산소 평형 목표
- 첫 번째로 고른 부유층의 연속 색면과 이후 부유층의 등치선·국소 지점
- 식물플랑크톤 `12`, 부유 분해균 `8`을 기준으로 한 절대 색 강도
- 동물 개체군·부유 먹이망·낮과 밤·미생물 순환·물질/기체 순환을
  독립적으로 접고 펼치는 시간 그래프

광원·경계의 열 출입 분해, 구조물 자체 온도와 열 장부 오차의 UI는 후속 범위다.

벡터 화살표를 화면 전체에 항상 표시하지 않는다. 기본 화면은 현재 두들 스타일을 유지하고, 관찰 지도에서 `수온`, `물 흐름`, `산소` 등을 필요할 때 겹쳐 본다. 숫자 탐침은 현재 위치의 값과 짧은 시간 추세를 제공한다.

부유층 색 지도는 현재 최고값을 다시 `100%`로 늘리는 상대 스케일을 쓰지
않는다. 그래야 물벼룩 섭식으로 식물플랑크톤이 절반으로 감소했을 때 화면
강도도 함께 감소한다. 여러 부유층을 동시에 고르면 첫 층만 연속 색면으로
두고 나머지는 등치선으로 분리해 반투명 구름이 중첩되어 읽을 수 없게 되는
문제를 막는다.

사용자가 `수조 전체` 보기를 고른 동안에는 살아 있는 선택 대상 스냅샷이
갱신되어도 관찰 탭과 스크롤 위치를 바꾸지 않는다. 선택 대상이나 보기
종류가 실제로 달라질 때만 새 내용의 시작점으로 이동한다. 카메라는 전체
맞춤 배율보다 `28%` 더 축소할 수 있고 cover 기준 `50%`를 기술 하한으로
두어, 패널을 띄운 상태에서도 수조와 기록을 함께 볼 수 있다.

## 12. 송사리 모델과 근거

### 12.1 유지한 현실 관계

- 송사리는 물기둥을 헤엄치며 움직이는 작은 먹이를 시각적으로 찾는다.
- 포식 가능한 먹이 크기는 물고기의 입과 몸 크기에 제한된다.
- 암컷은 수정란을 잠시 몸에 달고 다닌 뒤 가는 수초·조류 같은 기질에 붙인다.
- 알 발생 속도, 활동과 생존은 수온·산소 조건의 영향을 받는다.
- 개체는 알→치어→어린 개체→성체 순으로 성장하고 노화·자연사를 가진다.

### 12.2 현재 구현

송사리는 개체별 위치·속도·방향·성별·나이·수명·생애 단계·구조 생체량·저장량·번식 저장량·건강·행동 표적을 가진다. 현재 동물성 먹이의 국소 감지 반경은 `360` 세계 단위다. 반경 안 후보만 공간 구역에서 얻고, 실제 돌 다각형의 시야선과 몸집 적합도를 검사한다.

주 먹이는 큰물벼룩이며 실제 구조량이 입 크기에 맞는 어린 체리새우만 보조 먹이다. 식물플랑크톤, 표면 규조류·붓뚜껑말, 생물막과 나사말은 직접 먹지 않는다. 나사말은 후보를 삭제하는 이진 피난처가 아니라 국소 수관 밀도와 송사리의 상대 위치에 따라 발견·포획 가능성을 낮춘다. 송사리도 같은 수관에 들어오면 이득이 감소하지만 잎 사이 잔여 차폐가 0이 되지는 않는다.

물벼룩은 가까이 접근 중인 송사리에는 낮과 밤 모두 직접 도주한다. 넓게 퍼진 위험 단서만 있을 때는 낮에만 `34` 거리의 국소 네 방향에서 `위험 단서 × 시각 노출`을 비교한다. 위험 단서가 없거나 나사말이 국소 범위 밖이면 수초 위치를 알지 못하며, 밤의 확산 단서만으로 방향성 이동을 만들지 않는다. 수관 외곽과 성장 크기는 광량 계산의 기하 캐시와 `96` 단위 공간 구역을 재사용한다.

```text
포획 성공률
= 거리 접근도
× 시야 확보
× 먹이 크기 적합
× (1 - 나사말 차폐)
× 현재 공격 상태
```

포식된 질량은 몸 저장·배설·호흡 장부에 한 번만 이동한다. 같은 섭식량을
비물질성 `recentIntake` 위 내용물 신호에도 기록하고 `45초` 지수 배출로
감소시킨다. 위 용량은 현재 구조량의 `8%`이며 식욕이 절반 이상 회복되기
전에는 새 표적을 얻지 않는다. 성장·번식 욕구와 최근 포만을 분리해,
먹은 직후에도 생리적 부족분만 보고 연속 포획하던 경로를 막는다.

모든 생애 단계는 먼저 유지비를 지불하고 체급 비례 비축분을 남긴다.
치어와 어린 개체는 그 뒤의 순잉여를 구조 성장에 사용한다. 성체 암컷은
같은 순잉여에서 실제 알 질량을 번식 저장량으로 먼저 옮기므로 남은
성장량이 줄어든다. 수컷의 번식 비용은 별도 가상 생체량이 아니라
구애·추적 활동 대사로 지불한다. 따라서 성숙 전후의 차이는 고정된
먹이 비율이 아니라 실제 번식 비용에서 발생하며, 어느 단계도 나이만으로
구조 질량을 얻지 않는다.

성체의 선택적 체성장은 성숙 구조량에서 최대 구조량까지 진행한 비율을
`p`라고 할 때 성장 속도 상한에 `(1 - p)^2`을 곱해 연속적으로
감속한다. 또한 성장에 쓸 수 없는 비축 하한은 최대 체급 기준 저장 용량의
`40%`로 두어, 성장 직후의 상태 점수가 사냥 종료선 `0.56` 아래로
떨어지지 않게 한다. 따라서 성체는 먹이가 충분하면 계속 커질 수 있지만,
아직 최대 크기가 아니라는 이유만으로 포만과 사냥 사이의 이력 상태에
붙잡혀 계속 포식하지 않는다.

구애는 건강한 성체 암수의 국소 조우, 암컷의 번식 물질·저장 에너지, 실제 최근 섭식을 함께 요구한다. 암컷은 알을 `12초` 동안 운반한 뒤 나사말·가는 조류·대체 표면 순으로 부착한다. 알은 국소 수온의 번식 반응, 용존산소와 독성 노폐물 적합도를 곱해 발생하며 25°C 기준 `95초` 후 부화한다.

송사리 섭식 질량은 동화 `60%`, 배설 `25%`, 먹이 섭취 호흡 `15%`로 나뉘어 체리새우·균·생산자와 같은 닫힌 탄소·질소·산소 장부로 들어간다. 포식된 동물은 사체를 만들지 않으므로 같은 질량이 두 번 반환되지 않는다.

### 12.3 게임 보정과 한계

- 실제 발생 일수와 수명을 `95초`, `2,400~3,300초`로 압축했다.
- 산란량은 실제 번식량 재현보다 관찰 가능성과 개체 수 안정성을 위해 한 번에 혼성 한 쌍인 `2개`로 줄였다.
- 실제 수질 단위를 표방하지 않으므로 산소 `36/18`, 독성 노폐물 `5/20`은 기존 게임 수질 척도에서 보정한 연속 스트레스 기준이다.
- 어린 체리새우 포식은 송사리의 움직이는 소형 먹이 탐지와 먹이 크기 선택 연구를 게임 먹이망에 적용한 관계다. 이 수조 조건에서 두 종의 포식률을 직접 측정한 값으로 주장하지 않는다.
- 나사말 잎 하나하나와 3D 깊이를 충돌 계산하지 않고 2D 국소 차폐 밀도로 근사한다.
- 수초가 항상 물벼룩 피난처라는 규칙은 사용하지 않는다. 포식자 종류와
  수초 안 진입 여부에 따라 물벼룩의 선택이 반대로 나타나는 실험을 따라
  국소 상대 위험으로 근사한다.
- 위 내용물은 실제 위 부피나 실측 소화 시간을 재현하지 않는 압축 행동
  신호다. 물질 장부와 중복하지 않으며 장기 먹이망 결과로 재검증한다.
- 이상성 성장 모델의 번식 투자 계수는 먹이 한 끼의 고정 분율이 아니다.
  현재 압축 시간에서는 보존되는 알 질량·산란 간격과 성체 크기 진행률의
  제곱 감속 곡선으로 성숙 후 성장 둔화를 만들며, 장기 개체군 추세로
  다시 보정한다.
- 기술적 `512`개 안전선은 생태 수용량이 아니며 정상 평형을 만드는 데 사용하지 않는다.
